Sync your weight

Keep your Everyday Home Screen icon. Add a separate Apple Shortcut for weight sync.

1. Connect in Everyday

Sign in, open More → Weight sync → Connect weight Shortcut. Consent to uploading weight to your Firebase account and copy the private sync address. Treat it as a password for submitting weight. Never share it or screenshots containing it.

2. Read the latest sample

In Shortcuts, create “Sync Everyday Weight”. Add Find Health Samples: Type Weight, Unit lbs, Group by None, Sort by Start Date, Latest First, Limit 1. Remove the optional “last 7 days” filter if you want the most recent reading even when it is older.

Add an If action checking whether Health Samples has any value. Put the following actions inside that branch. Otherwise, show “No weight found” and stop.

3. Extract the value and date

Use Get Details of Health Samples (or the sample variable’s property picker) to obtain Value and Start Date from the found sample. Keep Value in pounds. Format Start Date twice:

  • Custom format yyyy-MM-dd → name this variable Weight Day. Use the phone’s local time zone.
  • ISO 8601, including time and time-zone offset → name this variable Recorded At.

Both dates must come from the sample, not the current date. The website validates the date, value and units again before saving.

4. Submit to your private address

Add Get Contents of URL with your private sync address. Set Method to PATCH, Request Body to JSON. Build this nested dictionary. Each object is a Dictionary field, and doubleValue must be a Number field containing the sample’s Value variable.

{
  "fields": {
    "sample": {
      "mapValue": {
        "fields": {
          "value": { "doubleValue": VALUE_VARIABLE },
          "unit": { "stringValue": "lb" },
          "date": { "stringValue": "WEIGHT_DAY_VARIABLE" },
          "recordedAt": { "stringValue": "RECORDED_AT_VARIABLE" }
        }
      }
    }
  }
}

Replace the three placeholders with Shortcut variables, not literal text. This is the Firestore API’s required encoding; do not paste it into Everyday’s backup importer.

For the first run, add Show Result after the request to inspect the response. A successful response contains fields.sample. If it contains error, the upload failed—do not show a success notification. Once verified, use an If action on the error field to display either the error or “Weight sent. Open Everyday to import it.”

5. Use your two icons

Add this Shortcut to your Home Screen. Tap it to send the latest weight, then open Everyday using your existing icon. Everyday checks on opening or returning (at most once per 30 seconds). More → Weight sync → Check for weight checks immediately.

The reading’s date is preserved. Existing manual weights win; a newer synced weight can update an earlier synced weight on the same day. Repeated and older samples are ignored. Only the most recently submitted sample waits for import, so open Everyday between weigh-ins. This version does not backfill history or mirror deletions from Health.

Disconnect

Use More → Weight sync → Disconnect, then remove the Shortcut or its URL. This revokes the address and deletes the pending sample and connection settings. Imported weights remain in your account and can be edited or deleted normally.

If you edit a synced weight manually, it becomes a manual entry and future syncs will keep it. Your exported backup contains imported weights, but never the private sync address.
