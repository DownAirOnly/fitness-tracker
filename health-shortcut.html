Sync weight + body fat

Keep your Everyday Home Screen icon. Use one separate Apple Shortcut to send the latest scale reading from Apple Health.

1. Connect in Everyday

Sign in, open More → Weight & body fat sync → Connect. Copy the private sync address. Treat it like a password for submitting scale data. Disconnect revokes it.

2. Read the latest weight

In Shortcuts, create “Sync Everyday Health”. Add Find Health Samples: Type Weight, Sort by Start Date, Latest First, Limit 1. If no weight exists, show “No weight found” and stop.

Get the weight sample’s Value and Start Date. Format Start Date twice:

  • yyyy-MM-dd → Weight Day
  • ISO 8601 with time-zone offset → Weight Recorded At

3. Read body fat when available

Add another Find Health Samples: Type Body Fat Percentage, Sort by Start Date, Latest First, Limit 1. Get its Value and Start Date. Format that date as yyyy-MM-dd and ISO 8601 too.

Only include body fat when its calendar day matches Weight Day. That prevents an older body-fat sample from being attached to a newer weight. Everyday accepts either a fractional Health value such as 0.224 or a display-style value such as 22.4 and normalizes it to 22.4%.

4. Submit to your private address

Add Get Contents of URL using the private sync address. Method: PATCH. Request Body: JSON. The required weight payload is:

{
  "fields": {
    "sample": {
      "mapValue": {
        "fields": {
          "value": { "doubleValue": WEIGHT_VALUE },
          "unit": { "stringValue": "lb" },
          "date": { "stringValue": "WEIGHT_DAY" },
          "recordedAt": { "stringValue": "WEIGHT_RECORDED_AT" }
        }
      }
    }
  }
}

If same-day body fat exists, add these two sibling fields inside that inner fields dictionary:

"bodyFatPercent": { "doubleValue": BODY_FAT_VALUE },
"bodyFatRecordedAt": { "stringValue": "BODY_FAT_RECORDED_AT" }

Use Shortcut variables, not the placeholder words. Do not include the body-fat keys at all when no same-day reading exists.

5. Verify once

For the first run, show the request result. A successful response contains fields.sample. If it contains error, the upload failed. After verifying it, show a simple success message such as “Scale reading sent. Open Everyday to import it.”

How Everyday handles it

Weight and body fat are processed independently. A manual same-day weight stays in place, but a fresh body-fat reading can still attach to it. Newer synced weight replaces older synced weight. Repeated or older samples are ignored. Historical backfill and Health deletions are not synced.

Disconnect

Use More → Weight & body fat sync → Disconnect, then remove the Shortcut or its URL. Imported measurements remain in Everyday.
