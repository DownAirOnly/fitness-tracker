Sync weight + body fat

Everyday treats weight and body fat as separate measurement streams. One Shortcut can submit either one or both.

1. Connect in Everyday

Sign in, open More → Weight & body fat sync → Connect. Copy the private sync address. Treat it like a password. Disconnect revokes it.

2. Find the latest weight

Add Find Health Samples: Type Weight, Sort by Start Date, Latest First, Limit 1. If present, get its Value and Start Date. Format Start Date as yyyy-MM-dd for Weight Day and as ISO 8601 with time-zone offset for Weight Recorded At.

3. Find the latest body fat

Add another Find Health Samples: Type Body Fat Percentage, Sort by Start Date, Latest First, Limit 1. If present, get its Value and Start Date. Format Start Date independently as yyyy-MM-dd for Body Fat Day and ISO 8601 for Body Fat Recorded At.

The two dates do not need to match. Everyday accepts either a Health-style fractional body-fat value such as 0.215 or a display-style value such as 21.5.

4. Submit whichever measurements exist

Add Get Contents of URL with the private sync address. Method: PATCH. Request Body: JSON. Put the measurements inside fields.sample.mapValue.fields.

If weight exists, include:

"value": { "doubleValue": WEIGHT_VALUE },
"unit": { "stringValue": "lb" },
"date": { "stringValue": "WEIGHT_DAY" },
"recordedAt": { "stringValue": "WEIGHT_RECORDED_AT" }

If body fat exists, include these independently:

"bodyFatPercent": { "doubleValue": BODY_FAT_VALUE },
"bodyFatDate": { "stringValue": "BODY_FAT_DAY" },
"bodyFatRecordedAt": { "stringValue": "BODY_FAT_RECORDED_AT" }

You may send weight only, body fat only, or both. Do not include a partial measurement group.

5. Verify once

For the first run, show the request result. A successful response contains fields.sample. After verifying it, show a simple success message such as “Scale reading sent. Open Everyday to import it.”

How Everyday handles it

Weight and body fat have separate records, dates, source timestamps, duplicate handling, and history. A manual reading wins over an Apple Health reading of the same measurement type on the same date. Repeated or older Health samples are ignored independently.

Disconnect

Use More → Weight & body fat sync → Disconnect, then remove the Shortcut or its URL. Imported measurements remain in Everyday.
